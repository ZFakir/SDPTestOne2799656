The root `package.json` is the sole orchestrator: it declares npm workspaces (`apps/*`, `packages/*`) and boots both servers via `concurrently` in `npm run dev`. Cross-child coupling is strictly one-directional — `apps/web` and `apps/api` import JSON DTO shapes from `packages/shared/src/types.ts`, making that file the single source of truth for the REST contract. The web app calls the API through a typed client (`apps/web/src/lib/api.ts`) against the endpoints documented in README §6; the API owns all persistence under `storage/` (SQLite WAL + cloned repo mirrors). `scripts_and_storage` sits outside the workspace graph and is invoked directly to independently re-derive metrics from git and diff them against the running API, acting as an external oracle rather than a runtime dependency of either child.
