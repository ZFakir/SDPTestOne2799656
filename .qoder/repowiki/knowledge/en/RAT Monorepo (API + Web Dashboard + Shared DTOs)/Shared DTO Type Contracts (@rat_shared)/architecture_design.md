Single-file type-only package `@rat/shared` with no runtime code. `src/index.ts` re-exports only types via `export type * from './types'`, and `package.json` points both `main` and `types` to that entry so sibling workspaces consume it as a pure type dependency without emitting or bundling JavaScript. `src/types.ts` is organized into horizontal domain sections separated by comment blocks: repositories & jobs, commits & authors, paths, metrics (object/directory/author/timeseries), common envelopes (`ListResponse<T>`, `RepositoriesResponse`), multi-repository comparison, and error bodies. Dependency direction is strictly one-way: other packages import these interfaces; this package has no internal dependencies.
