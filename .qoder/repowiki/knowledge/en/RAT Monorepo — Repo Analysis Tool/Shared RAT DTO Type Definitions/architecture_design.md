Single-file TypeScript package (`@rat/shared`) with no runtime code — `src/index.ts` re-exports only types from `src/types.ts`, which groups DTOs by domain (repositories & jobs, commits & authors, paths, metrics, common envelopes). The package is marked `private: true` in `package.json` and points both `main` and `types` to `./src/index.ts`, so it is consumed as a pure type dependency by sibling workspaces without emitting or bundling any JavaScript. Dependency direction is one-way: other packages import these interfaces; this package has no internal dependencies.
