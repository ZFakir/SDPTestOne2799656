Children communicate exclusively through the `Services` interface in `src/services.ts`, which is constructed once at bootstrap (`index.ts`) and passed into every router. The pipeline layer (`ingest_pipeline`) drives the `git_layer` to clone/parse repos and writes facts consumed by `analysis_and_metrics`; both layers persist via `db_layer` (WAL-mode SQLite). Route handlers in `rest_routes` call `services.pipeline` for write-heavy operations and `services.db` / `services.queue` for reads and async jobs, with `requireRepository` / `requireReadyRepository` enforcing status checks before analysis. Test suites mount the same Express app from `app.ts` but inject a temp DB and mocked services via `test/helpers/testApp.ts`.
