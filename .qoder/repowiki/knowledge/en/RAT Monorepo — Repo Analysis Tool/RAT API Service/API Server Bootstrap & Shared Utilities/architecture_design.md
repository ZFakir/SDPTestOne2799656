Four entry points form a strict bootstrap chain: `index.ts` is the process entry that loads config via `loadConfig()`, opens the SQLite DB via `openDatabase()`, builds shared services through `createServices()` (which also calls `ensureStorageDirs`), marks stale jobs failed on restart, then mounts the Express app from `app.ts`. `app.ts` is an Express factory (`createApp`) that wires CORS, JSON parsing, a `/api/health` probe, and all route modules under `/api/repositories` and `/api/jobs`, finishing with `notFoundHandler` and `errorHandler`. `config.ts` resolves `.env` from repo root or cwd, derives absolute paths for `storageDir/repos/tmp/dbPath`, and exposes typed `Config`. `services.ts` defines the `Services` interface consumed by routers and provides `requireRepository` / `requireReadyRepository` helpers. The `util/` subdirectory holds cross-cutting helpers: `errors.ts` defines the `AppError` class plus `badRequest`/`notFound`/`conflict`/`payloadTooLarge` constructors used throughout; `paths.ts` centralizes per-repo directory layout (`repoDir`, `zipSrcDir`, `mirrorDir`); `zipSafe.ts` enforces zip extraction safety against path traversal, absolute paths, drive letters, and symlinks.
