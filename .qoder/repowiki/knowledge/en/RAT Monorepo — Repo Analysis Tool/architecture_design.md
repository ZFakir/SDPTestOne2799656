The root `package.json` declares npm workspaces (`apps/*`, `packages/*`) and is the only place that boots the system: `npm run dev` launches both `@rat/api` (Express on :4000) and `@rat/web` (Next.js on :3000) via concurrently; `npm run build` compiles both apps in order. Cross-child coupling is strictly one-directional: `apps/web` and `apps/api` both import from `packages/shared/src/types.ts` for the JSON DTO contract (repositories, jobs, commits, authors, paths, metrics, timeseries), so the API surface and response shapes are the single source of truth. The web app calls the REST endpoints defined in README §6 through a typed client (`apps/web/src/lib/api.ts`); the API owns all persistence under `storage/` (SQLite WAL + cloned repo mirrors). `scripts_and_storage` lives outside the workspace graph and is invoked directly (`bash scripts/makeFixtureRepo.sh`, `tsx scripts/verifyMetrics.ts`) to independently re-derive metrics from git and diff against the running API, acting as an external oracle rather than a runtime dependency of either child.
