Single-tenant Next.js 14 App Router app under `apps/web/`. The root layout (`src/app/layout.tsx`) provides site-wide header/nav/footer and imports global CSS plus the Mona Sans font. Pages live in `src/app/` — a static home page listing repositories and an `[repoId]` route for per-repo dashboards. All interactive pages are marked `'use client'` and consume data through a thin SWR layer in `src/lib/hooks.ts`, which wraps typed endpoints from `src/lib/api.ts`. The API module is the sole HTTP boundary: it exposes an `api` namespace of fetch/XHR calls to `/api/*` on a configurable `NEXT_PUBLIC_API_URL` (defaulting to `http://localhost:4000`), centralizes error mapping into an `ApiError(code, status, message)`, and normalizes commit-set filters via `filtersToParams` + `qs`. Shared UI is split by feature area under `src/components/`: `common/` (EmptyState, ErrorBanner, StatusBadge), `filters/` (AuthorSelect, FilterBar, PathPicker), `ingest/` (CloneUrlForm, ZipUploadForm, IngestTabs, JobProgress), and `metrics/` (tables + Recharts charts). Styling is CSS-only via `src/styles/globals.css`; no design system library is used. The package depends on `@rat/shared` for DTO types, which is explicitly listed in `next.config.mjs` under `transpilePackages` so the frontend can import its TypeScript definitions at build time.
